# 全量上下文解析工具

离线解析 Agent 会话的 JSONL 上下文转录：识别迭代、提取各轮工具调用，并按**读入 / 写入 / 编译**统计每次调用涉及的字符长度。

## 功能

- 上传或拖放 `.jsonl` / `.json` / `.jsonl.gz`（自动识别 gzip 解压），也可一键加载 `example/` 中的示例。
- 识别迭代：以「助手带工具调用的消息」为一轮，兼容 request 累积上下文与 response 增量两种日志形态。
- 提取各轮工具调用，配色区分：
  - 🔵 蓝 = 读入类工具（list_directory / read_file / get_file_structure / search_text / find_* 等）
  - 🔴 红 = 写入类工具（write_file / insert_at_anchor / delete_file / build_anchor_index 等）
  - 🟢 绿 = `compile_and_run`
- 字符长度：读入取工具结果长度，写入取写入内容（code / content）长度，编译取输出长度。
- 两种视图（筛选条「视图」切换）：
  - **调用列表**：按轮分组的调用条目，逐条看类型、状态与字符长度。
  - **按轮次整理**：自上而下按迭代顺序排列，每轮一个可折叠块，内容为 ① 推理内容 → ② 工具调用与结果。每个工具调用下方紧跟**其对应的结果**（`结果 #i`），结果默认压缩为一行摘要（状态 + 首行预览 + 结果字符/计入字符），点开可看原文；轮次顶部工具条可「全选 / 清空 / 展开结果 / 压缩结果」。
- 选定导出：在「按轮次整理」视图勾选任意轮次（勾选轮次会连带其全部调用）或单独勾选某几次调用，然后用「选定 Markdown / 选定 JSON」只导出这些内容。
- 筛选：按工具类型、调用结果、失败类别、工具名关键字、最小字符数，可仅显示含工具调用的迭代，可合并同名连续调用（按轮次整理视图会强制关闭合并以保证配对）。
- 导出（可仅导出当前筛选结果）：
  - **完整 JSON**：全部结构化字段（含参数与结果原文，恒含，不受附加项影响）。
  - **精简 JSON**：迭代 + 工具调用 + 字符长度，参数/结果按各自开关决定是否附带。
  - **CSV**：每次调用一行，含参数/结果字符长度；开启对应开关时追加「工具参数 / 工具结果」列。
  - **Markdown**：汇总 + 调用明细表格，参数/结果按各自开关决定是否加列。
  - **轮次 Markdown**：按轮次整理导出，每轮 ① 推理内容 ② 工具调用与结果（调用下方紧跟其结果）。
  - **纯工具 + 字符**：每行一次调用，便于 grep / 排序，开关开启时追加 `[参数]` / `[结果]` 段。
  - **仅参数 Markdown / 仅结果 Markdown**：单卷导出，一次只产出参数原文或结果原文，互不掺杂、也不受附加项开关影响。
  - **选定 Markdown / 选定 JSON**：仅导出勾选的轮次与调用，汇总口径也按所选内容计算。
- 导出附加项（各自独立，互不影响；默认：推理内容开、工具参数关、工具结果关、结果移到文末附录开）：
  - 「含推理内容」：附加每轮推理内容与助手文本。
  - 「含工具参数」：只控制参数原文（`function.arguments`），JSON 同时给出结构化 `args`；关闭后任何格式都不写参数原文，只留「参数字符」统计。
  - 「含工具结果」：只控制结果原文；关闭后任何格式都不写结果原文（连「失败原因」列也只留占位），只留「结果字符」统计。
  - 「结果移到文末附录」：勾选后结果原文集中到文件末尾的「附录：工具结果」，正文每次调用只留 `→ 附录 Rn` 引用与摘要，长结果不会把参数与调用结构冲出视野；取消勾选则结果内联在调用下方。
  - 未勾选的附加内容不会被静默丢弃：Markdown 类导出会在原位标注「导出设置：不含工具参数 / 工具结果」，JSON 的 `include` 记录 `toolArgs` / `toolResult` / `toolResultMode` / `omitted`；参数字符数、结果字符数与字符统计恒定保留。
  - 导出完成后状态栏会回显本次的「推理 / 参数 / 结果（位置）」开关状态，便于确认设置是否生效。

## 启动

需 Node.js（仅用内置模块，无需 npm 安装）。

- Windows：双击 `run.bat`（自动打开 http://localhost:8317）。
- 任意平台：`node server.js`。

端口默认 8317（已避开 8080），被占用时自动向后寻找可用端口。

> 说明：`run.bat` 内容为纯 ASCII、全部单行命令、CRLF 行尾，请勿用会改行尾或加中文的编辑器随手改它——LF 行尾 + 跨行括号块会让 cmd.exe 解析错位，表现为窗口闪退。若 8317 已被占用，服务会后退到 8318+ 并打印实际地址，浏览器可能仍停在 8317，请以控制台地址为准。

```
context-parser/
├── index.html      前端结构
```

## API

- `GET /api/examples` — 列出示例文件。
- `GET /api/example?name=<file>` — 解析并返回指定示例的结构化结果。
- `POST /api/parse` — 请求体 `{ name, data }`，`data` 为文件内容的 base64，返回结构化分析结果。
